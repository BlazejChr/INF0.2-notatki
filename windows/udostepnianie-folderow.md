# INF0.2 - Udostępnianie sieciowe folderów

Dzięki udostępnianiu sieciowemu folderów jesteśmy w stanie dzielić ten sam folder na różnych komputerach.

### 1. Tworzenie dysku sieciowego
Mamy 3 sposoby aby to zrobić
**1. PPM (na folder który chcemy udostępnić) > Właściwości > Udostępnianie > Udostępnij**
**2. PPM (na folder który chcemy udostępnić) > Właściwości > Udostępnianie zaawansowane > Udostępnij ten folder**
**3. CMD > net share**

### 2. Mapowanie dysku sieciowego
Aby otworzyć udostępniony folder musimy:
**PPM (ten komputer) > Mapuj dysk sieciowy > Folder (wklejamy ścieżkę do folderu)**

Ewentualnie możemy wpisać jego ścieżkę w menadżerze plików
