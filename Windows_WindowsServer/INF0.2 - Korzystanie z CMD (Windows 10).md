# INF0.2 - Korzystanie z CMD

### 1. Najważniejsze polecenia:

- `dir` — wyświetla pliki z folderu, w którym jesteśmy
- `cd nazwa_folderu` — przechodzimy do danego folderu
- `mkdir nazwa_folderu` — tworzy folder
- `rmdir nazwa_folderu` — usuwa folder
- `move nazwa_folderu nowa_lokalizacja` — zmienia lokalizację folderu albo pliku
- `xcopy /e nazwa_folderu nowa_lokalizacja` — kopiuje folder (z podfolderami) do danej ścieżki
- `copy nazwa_pliku nowa_lokalizacja` — kopiuje pojedynczy plik do nowej lokalizacji
- `systeminfo` — podstawowe informacje o podzespołach
